## 3. Losses first — the `twins` regression, isolated to W1 alone

Diagnostic-only re-run, `--only twins` (90 pages, no tuning, no params
changed), four configs: candidate, control, L1-only (W1 forced off),
W1-only (L1 forced off):

| config | CER | WER | F1 |
|---|---|---|---|
| candidate (L1+W1) | 13.865% | 48.029% | 56.009% |
| L1-only (W1 off) | 11.634% | 41.971% | 60.391% |
| W1-only (L1 off) | 13.865% | 48.029% | 56.009% |
| control (both off) | 11.634% | 41.971% | 60.391% |

**L1-only is numerically identical to control. W1-only is numerically
identical to candidate.** L1 (`lines.isolated_mark_height_fraction`) has
*zero* measurable effect on `twins` — its trigger condition never fires on
this content. The entire 2.23pp regression is W1
(`words.short_split_x_heights`) alone.

Top confusions, `twins` only, candidate vs control:

| pair | candidate | control | Δ |
|---|---|---|---|
| `" " -> ""` (space deleted) | 265 | 58 | **+207** |
| `"" -> " "` (space inserted) | not in top 12 (below cutoff) | 57 | large decrease |
| `O -> 0` | 238 | 240 | −2 (unaffected) |
| `O -> o` | 150 | 149 | +1 (unaffected) |
| `l -> 1` | 126 | 127 | −1 (unaffected) |

The look-alike-character confusions the `twins` category exists to stress
(`O`/`0`, `O`/`o`, `l`/`1`, `I`/`l`, `B`/`8`, `5`/`S`, `Z`/`z`) are
**unaffected** — same counts within noise, both configs. The regression is
entirely **inter-word space collapse**: W1's fix for over-splitting compact
identifier-like runs (`docs/measurements/2026-09-27_W1.md`,
`docs/measurements/2026-09-26_c15_tableseg.md`) is now merging genuinely
separate short words into one, specifically where those words are built
from narrow, confusable glyphs (`l`, `1`, `I`, `O`, `0`) bunched close
together — exactly the shape `twins` was built to contain, and exactly the
shape W1's "compact run" gate (`SHORT_SPLIT_MEMBERS=3`,
`words.short_split_x_heights`) was authored to recognise as *one*
identifier rather than several words. W1 cannot currently tell those two
cases apart. This is the same word-fusion failure mode 12b already named
on pages-cov generally; W1 measurably improves it in aggregate (pages-cov
`" "->""` fell from 1170 in 12b's own fitted run context down materially
here too) but **overcorrects specifically on this content shape**, and the
overcorrection is concentrated, not diffuse.

## 5. What this means for other agents

- **`ocrcer-runtime`** (owns segmentation/word-splitting, `words.rs`): W1's
  compact-run gate needs a way to distinguish "one identifier-shaped run
  that was wrongly split" from "two short words, each built from narrow
  look-alike glyphs, that happen to sit close together." Right now it only
  looks at x-height/run-length signals, which both cases satisfy
  identically. A plausible next lever — not a decision this report makes —
  is checking whether the candidate merge crosses a gap that is *also* a
  plausible inter-word space by absolute width, not just by x-height
  ratio, before applying the merge.
- **`ocrcer-architect`**: whether that lever is a segmentation-heuristic
  tweak (in scope for `ocrcer-runtime` alone) or needs a new signal in the
  feature vector or word-boundary evidence format is a decision, not
  something this report is positioned to resolve — flagging it rather than
  picking for you, per this role's scope boundary.
- **`ocrcer-linguist`**: no lexicon or bigram signal is implicated here —
  the confusion table for `twins` is unchanged character-for-character
  between candidate and control (§3); the loss is purely a segmentation
  event before any character gets matched or decoded.
- **`ocrcer-glyphs`**: no font-coverage gap is implicated — the affected
  faces (STIX Two Math, Noto Serif, Roboto Condensed, PT Sans, Liberation
  Serif, all at 14px) are exactly the faces already in the bank; this is
  not a missing-glyph-shape problem.
- No lever is proposed for the `technical` category's smaller regression
  (+0.385pp, 9/90 pages) — its mechanism was not isolated this round; if
  it recurs or grows in a future score-once run it is worth a similar
  `--only technical` decomposition.

## 6. Bottom line

L1+W1 together are a net win on both scoring corpora on every headline
metric except one (pages-cov recall, −0.415pp) and win finfilings — the
real, private corpus — cleanly across all six metrics with only two
trivially-regressed pages out of sixty. That is not the whole picture:
**`twins`, a 90-page category built specifically to stress look-alike
character pairs, regresses 2.23 percentage points of CER under this same
change, driven entirely by W1, and the mechanism is well isolated and
concentrated (45 of 90 pages), not noise.** Both facts are true at once
and neither is reported ahead of the other. No parameter was touched as a
result of this run — this is a report, not a tuning round.
