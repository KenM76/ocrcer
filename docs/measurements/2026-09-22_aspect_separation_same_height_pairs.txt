Yardstick. Feature 103 is computed from the SOURCE tight-crop bitmap, not
from the 32x32 normalised grid, so a pixel of it is a pixel at the render
size. d/dw of (w-h)/(w+h) is 2h/(w+h)^2. At 24 px/em an authored-face cap
height is 0.70*24 = 16.8 px and a zero is about 13 px wide, so one pixel of
width moves this feature by about 0.038. Read every number above against
that: below 0.038 the pair is inside one pixel of rasterisation.
