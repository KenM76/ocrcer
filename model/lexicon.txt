# lexicon.txt -- the authored word list.
#
# Per CLAUDE.md rule 2, every entry here is authored from knowledge. Nothing
# was scraped, downloaded, or adapted from a word list of unknown provenance,
# because the entire licence case for this project is that the tables are an
# original work.
#
# Per CLAUDE.md rule 6 the lexicon is a BONUS and never a constraint. A word
# absent from this file loses the bonus; it is never penalised, never
# rewritten, and never overridden, and inside identifier-shaped context the
# bonus is suppressed outright. So a gap in this list costs a little accuracy
# on prose and costs nothing at all on a part number -- which is the trade
# this domain wants.
#
# FORMAT
#
# Section headers select the attributes that apply to every line beneath
# them, until the next header:
#
#   [tier T | class C | domain D]
#
# then one base form per line. Blank lines and `#` lines are ignored.
#
# tier   1..5, an AUTHORED frequency band, not a measured frequency. 1 is the
#        closed-class core that appears in nearly every English sentence; 5 is
#        a term that is needed but rare. The decoder scales the lexicon bonus
#        by tier, so the band is a claim about how much evidence membership
#        provides, not a count. Tier assignments are a judgement and are on
#        chunk 8's tuning list as a group -- but note what is NOT at stake:
#        getting a tier wrong changes the size of a bonus, never whether a
#        string is allowed.
#
# class  the inflection class. `ocrcer-build` expands each base form by the
#        authored English spelling rules in `lexicon.rs`; the expansion is a
#        deterministic script, so the generated forms are rule-1 clean without
#        being typed out here.
#          -   invariant. Nothing is generated.
#          n   noun.       +s / +es / y->ies
#          v   verb.       +s/+es, +ed/+d, +ing, with final-consonant doubling
#          a   adjective.  +er, +est, +ly
#          nv  noun and verb
#          na  noun and adjective
#          av  adjective and verb
#
# domain a label carried for auditing only. It tells a reader why a word is
#        here. The runtime never sees it.
#
# A note on what is deliberately absent: no proper names of people, no brand
# names, and no product names. They are the entries most likely to be wrong
# in a way that matters, and rule 6 means their absence costs nothing.
#
# Also absent, and this one is a rule rather than a taste: NO FORM THAT MIXES
# LETTERS AND DIGITS. `T4`, `RC59`, `GST34` and the rest of the CRA form names
# were in this file and have been removed. The decoder judges a word
# identifier-shaped when at least `decode.identifier_digit_fraction` of its
# characters are digits and at least one is a letter, and it suppresses the
# lexicon term entirely inside such a word -- `T4` and `M8` are the same shape
# to that test, by design, because rule 6 exists to stop `M8x1.25` becoming a
# dictionary word. So a mixed form can never earn its bonus: it is dead weight
# in the DAWG, not knowledge. Do not re-add one, and do not soften the gate to
# make one work.
